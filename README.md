# 进位制转换步骤演示器

一个使用 Python 标准库 Tkinter 编写的桌面演示器，将进制互转、位权展开、除基取余和乘基取整整合在同一界面中。

## 运行

需要安装 Python 3，并确保当前 Python 环境包含 Tkinter。无需安装第三方依赖。

```powershell
python main.py
```

## 功能

- 支持二进制、八进制、十进制和十六进制任意互转。
- 支持正数、负数和小数；十六进制数位使用 `A`–`F`。
- 展示源数按位权展开、十进制中间值、整数除基取余和小数乘基取整的过程。
- 小数精度可设为 1–64 位，并可选择截断或四舍五入。
- 使用精确分数进行中间计算，避免浮点误差；不能有限表示的小数会提示循环或精度处理情况。

## 转换原理

任意进制转十进制时，按位权展开求和。例如：

```text
(101101)₂ = 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = (45)₁₀
```

十进制整数转其他进制时连续除以目标基数，余数倒序读取；十进制小数则连续乘以目标基数，依次读取乘积的整数部分。小数不能有限表示时，演示器按选择的精度截断或四舍五入。

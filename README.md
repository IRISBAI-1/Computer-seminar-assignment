# 进制转换步骤演示器

> 数网知来组 · 《计算机专业基础研讨》

一个用 Python 标准库 Tkinter 写的桌面小工具，把二进制、八进制、十进制、十六进制之间的换算**一步一步摊开演给你看**：源数怎么按位权展开、十进制整数怎么除基取余、十进制小数怎么乘基取整，每一步的商、余数和取到的数位都写在演算日志里，配合逐行动画和结果横幅，比背公式直观得多。

界面沿用了 `design/prototype/进制演示.html` 的布局与配色，右侧状态插画同样存放在 `design/prototype/`。

---

## 功能特性

- **任意互转**：二进制、八进制、十进制、十六进制之间任意方向互转；非十进制互转时日志自动分成前后两段——先按权展开算出十进制中间值，再除基/乘基转到目标进制。
- **支持正负数与小数**：`-FF.A`、`0.1`、`101.01` 这类写法都能算；十六进制数位使用 `A`–`F`。
- **四段式演算日志**：按「按权展开 → 除基取余 → 乘基取整 → 转换结果」固定分段，小节标题高亮，结果单独标注。
- **精确计算**：中间值用 `fractions.Fraction` 做有理数运算，不经过浮点数，`0.1` 这类数值不会出现二进制浮点误差堆积。
- **精度可控**：小数位数 1–64 位（默认 12 位），处理方式可选「截断」或「四舍五入」，第 N+1 位是几、是否进位都会写进日志。
- **循环小数提示**：检测到小数部分出现重复余数时，会点明循环从小数位第几位开始。
- **输入校验**：数位不属于所选进制（如在二进制里填 `2`）、格式错误、空输入都会给出中文提示，并联动错误插画与红色状态。
- **交互动效**：单定时器补间引擎（约 60fps，按真实时间计算进度，掉帧不跳步）、圆角按钮悬停/按下过渡、结果横幅「点亮」变色、演算日志逐行揭示、日志区滚轮惯性滚动、启动入场动画、状态插画起落、精度设置窗口淡入。

## 环境要求

- Python 3.8 及以上（开发与实测环境：Python 3.15 / Windows）。
- 需要 Tkinter，Windows 官方安装包默认自带；**无任何第三方依赖**。
- 需在仓库 `01/` 目录下运行：程序按 `__file__` 定位 `design/prototype/` 里的状态插画。插画文件缺失时程序不会崩溃，只是右侧不显示图片。

## 使用说明

1. 在「输入数值」里填要转换的数，如 `1101`、`-FF.A`、`0.1`。
2. 用两个下拉框选择 **源进制** 和 **目标进制**（2 / 8 / 10 / 16）。
3. 点「开始计算」，或直接在输入框按回车。
4. 顶部结果横幅给出结论，例如 `结果：13    (1101)₂ = (13)₁₀`；下方演算日志按段展开全过程。
5. 点「精度设置」调整小数位数与舍入方式（设置对下一次计算生效）。
6. 点「清空」重置输入与面板。

窗口默认 1000×720，可自由缩放，最小 760×600；布局与文字折行会跟着窗口宽度重排。

## 转换原理

实现上统一走「先求精确十进制值，再分解到目标进制」的路径：

1. **源进制 → 十进制**：按位权展开求和，整数位权为 `base^i`，小数位权为 `base^(-i)`。累加用 `Fraction`，结果精确无误差。
2. **十进制整数 → 目标进制**：除基取余。反复「除以基数取余数」，余数出现顺序是低位到高位，所以最后要**逆序**读取。
3. **十进制小数 → 目标进制**：乘基取整。反复「乘以基数取整数部分」，整数出现顺序就是高位到低位，所以**顺序**拼接。小数不能有限表示时按所选精度处理。
4. **非十进制互转**：等价于第 1 步加第 2、3 步，日志自动分成两段演示。

### 示例：二进制转十进制

输入 `1101`，源进制 2、目标进制 10，日志实际输出：

```text
转换：(1101)₍2₎ → (10进制)

一、源数按位权展开
(1101)₍2₎ = 1×2^3 + 1×2^2 + 0×2^1 + 1×2^0
绝对值 = 13₁₀

二、十进制整数转10进制（除基取余）
13 ÷ 10 = 1，余数 3
1 ÷ 10 = 0，余数 1
余数从下往上读取：13

三、十进制小数转10进制（乘基取整）
小数部分为 0，无需转换。
小数部分在 0 位后精确终止。

四、转换结果
(1101)₍2₎ = (13)₍10₎
```

### 示例：十进制转二进制（除基取余）

输入 `13`，源进制 10、目标进制 2：

```text
二、十进制整数转2进制（除基取余）
13 ÷ 2 = 6，余数 1
6 ÷ 2 = 3，余数 0
3 ÷ 2 = 1，余数 1
1 ÷ 2 = 0，余数 1
余数从下往上读取：1101
```

### 示例：小数与舍入（乘基取整）

输入 `0.1`，源进制 10、目标进制 2，精度 8 位、四舍五入时，日志会逐步列出 `1/10 × 2 = 0 + 1/5` 这类分数形式的乘基过程，提示「保留前 8 位：0.00011001；第 9 位为 1」并进位，同时说明「检测到循环小数，循环从小数位第 2 位开始」，最终得到 `0.0001101`。

```text

├── main_optimized.py      # 主程序：转换算法 + 动画增强版 Tkinter 界面（推荐运行）
```

## 已知限制

- 只支持 2、8、10、16 四种进制，不是任意基数。
- 只接受「可选正负号 + 数位 + 一个小数点」的写法，不支持科学计数法、千位分隔、空格或下划线。
- 小数结果按精度截断或四舍五入，不输出循环节括号写法（如 `0.0(0011)`），只用文字提示循环起点。
- 目标进制为 10 时仍会演示「除基取余」，日志略显重复，这是为了保证四段结构一致。
- 界面字体按 Windows 配置（`Microsoft YaHei UI` / `Consolas`），在 macOS/Linux 上会回退为系统默认字体。
- 状态插画依赖 `design/prototype/nailong_normal_tk.png`、`nailong_laugh_tk.png`、`nailong_ok_tk.png`，删掉后界面功能正常但右侧留白。

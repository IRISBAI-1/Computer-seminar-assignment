# 进位制转换步骤演示器

## 项目简介

进位制转换步骤演示器用于辅助学习不同进位制之间的数值转换。它不仅展示转换结果，也把计算过程拆解为逐步的位权展开、除基取余或乘基取整，帮助理解转换原理。

## 转换原理

### 任意进制转十进制

按位权展开后求和。整数部分从右向左的位权依次为基数的 \(0、1、2、\ldots\) 次方；小数部分从小数点后开始，位权依次为基数的 \(-1、-2、\ldots\) 次方。

例如：

```text
(101101)₂
= 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 0×2¹ + 1×2⁰
= 32 + 8 + 4 + 1
= (45)₁₀
```

### 十进制整数转其他进制

用目标基数连续相除，记录每一步的余数；当商为 0 时停止，按余数从下往上读取结果。

例如，将十进制数 45 转换为二进制：

```text
45 ÷ 2 = 22 余 1
22 ÷ 2 = 11 余 0
11 ÷ 2 =  5 余 1
 5 ÷ 2 =  2 余 1
 2 ÷ 2 =  1 余 0
 1 ÷ 2 =  0 余 1

从下往上读取余数：(45)₁₀ = (101101)₂
```

### 十进制小数转其他进制

用小数部分连续乘以目标基数，每一步乘积的整数部分就是对应的新进制数位；继续处理乘积的小数部分，直到小数部分为 0 或达到所需精度。

例如，将十进制小数 0.625 转换为二进制：

```text
0.625 × 2 = 1.25  → 取整数部分 1
0.25  × 2 = 0.5   → 取整数部分 0
0.5   × 2 = 1.0   → 取整数部分 1

从上往下读取整数部分：(0.625)₁₀ = (0.101)₂
```

> 有些进制的小数无法用有限位数精确表示。遇到这种情况时，转换结果需要按指定精度截断或舍入。

## 演示内容

演示器围绕转换步骤呈现计算过程，包括：

- 按位权展开并计算数值；
- 记录连续除基时的商和余数；
- 记录连续乘基时的乘积与取出的数位；
- 将中间步骤组合成最终结果。

转换时请确认输入数位在对应基数下合法。例如，十六进制中 `A` 至 `F` 分别表示十进制的 10 至 15。

## 适用场景

- 学习二进制、八进制、十进制和十六进制等进制的转换方法；
- 对照每一步计算，检查手工转换过程；
- 课堂讲解或自主练习进位制与位权的概念。
